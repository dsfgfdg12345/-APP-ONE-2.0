# 原生社区交友婚恋视频即时通讯双端APP源码ONE兔2.0

源码获取：ym7k.com/19840/

ONE 兔 2.0 是国内流传比较成熟的**原生 Android+iOS 双端社交婚恋 APP 源码**，区别于 UniApp、Flutter 跨端套壳方案，客户端采用原生开发，重点强化实时 IM 聊天、音视频通话、动态社区、同城婚恋匹配能力，配套 PC 管理后台、H5 端，整套源码交付，适合搭建相亲婚恋、同城交友、兴趣社区类平台，也是很多社交服务商早期选型的经典社交底座。

## 技术架构特点

客户端：Android 原生 + iOS 原生，不是跨端打包，原生开发在 IM 消息、音视频通话、相机、相册、推送、定位等系统能力上稳定性更好，音视频延迟更低，适合强实时社交场景。
后端：PHP（ThinkPHP）+ MySQL + Redis，WebSocket 负责即时消息推送；
配套：PC 管理后台、H5 网页端；源码包含安卓端、iOS 端、后端、H5 全套代码，支持私有化部署、二次定制开发。

> 
> 对比跨端方案优势：原生对音视频、消息推送、后台保活优化更好；短板是维护成本高，Android、iOS 两端需要分别修改迭代。

## 核心业务模块拆解

### 1. 用户资料、婚恋档案与智能匹配

婚恋是这套系统的核心场景。用户注册后完善个人主页、头像、相册、自我介绍、婚恋标签：年龄、身高、学历、收入、婚况、择偶要求、兴趣标签。支持实名认证、人脸核验（可选扩展），提升平台可信度。
内置 LBS 同城定位，支持附近的人、条件筛选匹配：按地区、年龄、身高、择偶需求定向检索；支持心动、喜欢、互相匹配（双向配对），匹配成功后解锁聊天权限，是婚恋平台经典玩法。

### 2. 即时通讯 IM（文字 + 语音 + 图片 + 视频通话）

整套系统的核心能力：WebSocket 实时消息，支持私聊文字、表情、图片、语音消息、短视频消息；支持**一对一音视频通话**。
消息状态已读、未读、撤回、消息推送；支持黑名单、防骚扰、消息阅后即焚等配置。后台可管控聊天敏感词、消息审核，拦截违规内容。

### 3. 社区动态、短视频广场

兼顾泛社交社区属性，用户可以发布图文动态、短视频，支持点赞、评论、收藏、分享。广场推荐流、关注流、同城动态，兼顾婚恋相亲和兴趣社区两种玩法，提升用户留存。平台可以设置动态审核，发布内容先审后展示。

### 4. 会员、充值、付费变现体系

主流社交平台变现模块全部内置：

- VIP 会员：会员解锁无限打招呼、看访客、隐身访问、置顶、优先匹配、去广告；
- 金币充值：打招呼、发起聊天、看联系方式、赠送礼物消耗金币；
- 礼物打赏：直播间 / 私聊赠送虚拟礼物，平台抽成；
- 推广分销：邀请好友注册充值，推广者拿佣金；
- 置顶推广：个人资料、动态付费置顶，增加曝光。

### 5. 访客、足迹、私信招呼

记录谁看过我的主页、我的访客记录；支持打招呼、发心动卡片，很多平台设置非会员打招呼次数限制，作为付费转化钩子。

### 6. 后台风控、举报、权限管理

PC 后台集中管理用户、动态、订单、充值、举报、敏感词库。
支持用户举报、违规账号封禁、动态下架、聊天记录溯源；RBAC 角色权限，区分管理员、审核员、财务；充值订单、金币流水、会员订单、提现记录完整留存，导出对账报表。

### 7. 附加配套能力

- 话题广场、活动发布：线下相亲活动、同城聚会报名；
- 广告管理：开屏广告、信息流广告；
- 推送管理：极光 / 个推推送对接；
- 数据看板：用户新增、活跃、付费、匹配、消息统计。
